## 🚀 Sobre mí

Construyo las herramientas digitales con las que los clientes de **Fibex Telecom** gestionan su servicio: desde la app móvil hasta las APIs de facturación y la configuración remota de sus equipos.

- 📱 **Mobile first:** apps híbridas iOS/Android con Ionic, Angular y Capacitor, cuidando el rendimiento y la UX.
- 💳 **Pagos seguros:** integración de pasarelas de pago y flujos transaccionales de punta a punta.
- 🌐 **Red automatizada:** librerías y scripts que orquestan dispositivos para que el cliente se autogestione sin llamar a soporte.
- ⚡ **Cómo trabajo:** código limpio, modular y seguro por defecto.
